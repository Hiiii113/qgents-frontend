# Design System: Qgents — 案头朱批（Desk & Vermilion）

> 这是原型的视觉体系与落地对照。原型入口 `index.html`，样式 `assets/app.css`，交互 `assets/app.js`。
> 本文替代旧的「出发板」体系（深墨牌头带 + 中性纸白 + 同族蓝 + 完全扁平）。旧体系的配色、圆角、层级表达一律不继承。

## 一句话

白色案头、石墨结构线；朱砂只写人做的决定——派活、待审、叫停、当前所在——Agent 的过程一律用石墨灰阶呈现。

味觉上刻意冷、硬、克制：圆角收到 4–8px，没有渐变和玻璃，深色只出现在主按钮与 Agent 标签这类"实心动作"上。界面读起来像一张摊开的工作台，而不是一块牌头。

## 为什么这样定

- 产品核心是**人在派活、人在审分支**，机器在跑。颜色是稀缺资源，全留给人的判断点，运行过程靠灰阶和一条脉动点说话，不会抢走对话的注意力。
- 用户要求"简洁、舒适、易用，不做过度夸张"，所以没有装饰性插画、没有大面积色块、没有第二条强调色。
- 桌面浏览器为主、长时间使用：正文 16px、行高 1.65，结构靠留白与 1px 行界，不靠卡片套卡片。

## 颜色

### 面

| Token | 值 | 用途 |
| --- | --- | --- |
| `--surface` | `#FFFFFF` | 主画布、对话框、浮层 |
| `--surface-soft` | `#F6F7F8` | 群聊列、执行轨迹、运行卡、选中行 |
| `--surface-sunken` | `#EEF0F2` | 输入框内衬、表头、代码底、悬停 |
| `--surface-rail` | `#FCFCFD` | 左侧竖轨 |

### 墨

| Token | 值 | 用途 | 对比度（白底） |
| --- | --- | --- | --- |
| `--ink-900` | `#14171A` | 标题、正文 | 17.9:1 |
| `--ink-700` | `#333A41` | 控件文字、表单标签 | 11.4:1 |
| `--ink-500` | `#59626B` | 说明、次要正文 | 6.4:1 |
| `--ink-400` | `#6E7780` | 元信息、时间、占位 | 4.6:1 |
| `--ink-300` | `#9AA3AC` | 图标与禁用态，**不承载文字** | — |

### 线

`--line #E3E6E9`（行界、分隔）、`--line-strong #CED4DA`（控件边框，与底色区分）。

### 朱砂 —— 只标记人的决定

| Token | 值 | 只管这些事 |
| --- | --- | --- |
| `--mark` | `#B03A2B` | 选中项标记、当前导航、运行中、链接、焦点环 |
| `--mark-strong` | `#8C2B1F` | 叫停、退回、朱砂底上的文字 |
| `--mark-soft` | `#F9EAE7` | 派活对象的 chip、叫停步骤底、选区背景 |

`--mark` 白字对比 6.0:1，可作正文色。它不出现在普通按钮底、不禁用于装饰。

### 状态（与朱砂分工明确）

| Token | 值 | 含义 |
| --- | --- | --- |
| `--ok` / `--ok-soft` | `#1F6B4A` / `#EAF3EE` | 完成、已启用、已合并 |
| `--wait` / `--wait-soft` | `#8A5A00` / `#F8F0DF` | 待审批、待接受邀请、送达未读 |
| `--danger` | `#A2261C` | 归档、移除等不可逆确认按钮 |

**规则**：朱砂=人的动作与当前位置；琥珀=等别人；墨绿=已经成了；深红=不可逆。四者不同时出现在同一行。

## 字体

品牌字体沿用 Geist，中文回落到 `PingFang SC / Microsoft YaHei / Noto Sans SC`（必须写在 generic 之前）。等宽用 Geist Mono，只给时间、编号、仓库名、代码、diff。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 30 / 1.15，字距 −0.03em | 600 | 页面标题，一屏一次 |
| Title | 24 / 1.25 | 600 | 团队名、分支名、对话框标题 |
| Section | 20 / 1.4 | 600 | 文档内区块、设置分节 |
| Body | 16 / 1.65 | 400 | 聊天正文、记忆正文、面板说明 |
| UI | 14 / 1.55 | 400–500 | 控件、表格单元、按钮、侧轨 |
| Meta | 13 / 1.5 | 400 | 表单标签、辅助说明 |
| Micro | 12 / 1.5 | 400–500 | 时间、计数、标签 |

**12px 地板**：没有比 12px 更小的文字；数字用 `tabular-nums`，数字与单位永远不折行。

## 间距、圆角、深度

- 间距：4 的倍数，只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。页面区块 24–32，卡片内 16–20，相邻控件 8–12。
- 圆角：输入与小件 4，卡片与面板 6，对话框与头像 8，标签 3，pill 999。**没有 14px 以上的卡片圆角。**
- 深度：只有浮层、对话框、抽屉用一层柔和投影（`0 12px 32px rgba(16,20,24,.12)`）。页面本身不用阴影分层，用底色面 + 1px 行界。

## 布局

外壳三列：左竖轨 64px｜内容区｜执行轨迹 348px。

```
┌────┬──────────────────────────────────────────────┐
│    │ 顶栏 56：团队 ▾ / 项目 ▾ … 搜索项目  通知 头像 │
│ 64 ├────────────┬───────────────────────┬─────────┤
│ 竖 │ 群聊列 288  │ 主画布                 │ 执行轨迹 │
│ 轨 │（仅聊天页） │                       │（仅聊天）│
└────┴────────────┴───────────────────────┴─────────┘
```

- 项目在**顶栏面包屑式切换器**里切，团队切换只放在产品设置的「团队」页签；不再有横贯整屏的深色牌头带。
- 项目业务导航是**左侧竖轨**（聊天 / Agent / 记忆 / Skill / 仓库），当前项用 2px 朱砂竖条标记；团队级视图换一组（项目 / 成员 / GitHub）。
- 执行轨迹默认常驻右侧，可收起；窄屏变右侧覆盖层。运行过程不再挤在对话气泡里，只在触发消息下方留一张运行卡。
- 群聊列只在聊天页出现，其余页面不加载也不占位。行高 56，当前项换成白底 + 1px 内框。
- 画布内容上限 1160px，正文行宽 68ch；文档页 72ch。
- 断点：1280（轨迹收窄）→ 1100（群聊列与轨迹变覆盖层）→ 900（竖轨转顶部横条，分栏合并）→ 760（表格单列堆叠，页头动作铺满）。

## 组件

| 组件 | 规则 |
| --- | --- |
| 竖轨项 | 图标 20 + 12px 标签，上下排列；悬停换 `--surface-sunken`；当前项墨色 + 朱砂竖条。 |
| 顶栏切换器 | 32px 高，`label` 12px 墨 400 + `value` 14px 墨 900；只切项目，团队切换不在这里；打开时是带搜索的浮层。 |
| 搜索项目 | 30px 高，软底无边框，⌘K / Ctrl+K 唤出浮层；输入即筛，回车进第一项。 |
| 群行 | 两行：群名 14/500 + 元信息 12；未读时间转琥珀；预览单行截断。 |
| 公告条 | 顶栏下方一整行，`--mark-soft` 底；一句状态 + 一个动作 + 关闭；断开时才出现。 |
| 状态页（403 / 404） | 全屏软底 + 居中白卡：品牌标记、等宽编码、24px 标题、一句原因、两条出口。 |
| 附件 | 30px 高的文本按钮（图标 + 文件名 + 大小），点开在看板弹窗里读全文；不伪造下载。 |
| 骨架 | 软灰条 + 1.1s 呼吸，只用在切换项目与重新同步；超过 300ms 才出现。 |
| 空态 | 标题一句 + 下一步一句，贴着它替代的列表位置；不画空盒子。 |
| 阻断面板 | 软底 + 1px 线：原因、后果、重连动作；替换掉不可用的列表。 |
| 消息 | 32px 方形头像（人用首字母、Agent 用品牌标记），12px 列距；正文 16/1.65，行宽 68ch；人 20px 组距，跨人 24。 |
| 运行卡 | 软底 + 1px 线，圆角 6，内距 10/12；状态点 + 状态词 + 步数 + 一个动作（运行中=停止，完成=审阅分支，叫停=查看改动）。 |
| 执行轨迹 | 每步一行：序号圈 + 名称/工具 + 用时；运行中序号转朱砂并脉动；叫停步骤墨底朱字，后续步骤降到灰。 |
| 表格 | 表头 12px 墨 400，行 12px 上下留白，单条行界；项目名可点，主列 2 倍宽。 |
| 标签 | 20px 高、12px、圆角 3；`Agent` 用墨底白字，其余用软底。颜色永远是"状态 + 文字"双通道。 |
| 表单 | 标签 13/500，字段间 16，错误信息在字段下方并说明原因；失焦校验，提交时统一校验。 |
| 按钮 | 主按钮墨实心 34/4；次按钮白底 1px 线；文字按钮只有朱砂色，不加框；危险按钮深红；禁用降到 50%。 |
| 浮层 | 260–320 宽，圆角 6，一层投影；菜单项 8px 内距，当前项右侧朱砂小方块而不是对勾。 |
| 对话框 | 原生 `<dialog>`，520 宽，24 内距，`::backdrop` 32% 墨；破坏性操作要输入名称确认，或就地两步确认。 |
| Diff | 文件列表 280 + 差异面板；等宽 12/1.7，新增行用墨绿 + `+`，`@@` 行转灰；动作是两个并排按钮，提交后置灰并留结果横幅。 |

## 状态清单

页面之外，这套原型必须能演示下面这些状态，且都从真实操作产生，不提供演示开关：

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| 加载 | 切换项目、重新同步 | 聊天区与仓库区骨架 |
| 空 · 群 | 新建项目 | 一句“这个群还没有消息”，输入区可用 |
| 空 · 仓库 | 新建项目未导入，或移除全部仓库 | 行空态 + 说明为什么不能派活 |
| 空 · Skill / 记忆 / 自定义 Agent | 新建项目 | 各自一行空态，详情区不显示假数据 |
| 运行失败 | 无仓库时派活 | 轨迹停在第 2 步标红，运行卡给原因和“去导入仓库” |
| 权限 | 团队角色降为成员后进成员管理或 GitHub | 403 页，两条出口 |
| 找不到 | 点聊天里的历史运行链接 | 404 页，说明记录保留 30 天 |
| 阻断 | 断开团队 GitHub App | 公告条 + 仓库页阻断 + 导入禁用 |

## 动效

- 时长：120ms（悬停、按下）、180ms（浮层、抽屉）、240ms（页面切换）。
- 曲线：`cubic-bezier(.2,.7,.2,1)`；只动 `opacity` 与 `transform`。
- 运行中的状态点是 1.6s 的呼吸，表示"在跑"，不是装饰。
- `prefers-reduced-motion: reduce` 时全部动画与过渡降到 0.001ms。

## 无障碍

- 正文对比 ≥ 4.5:1，元信息 4.6:1，图标与朱砂标记 ≥ 3:1。
- 焦点环统一 `2px var(--mark)` + 2px 偏移，键盘顺序即阅读顺序。
- 状态不靠颜色单独表达：标签带文字（待审批 / 已叫停），运行步骤既有颜色也有文案。
- 抽屉与浮层都能 Esc 关闭并把焦点还给触发按钮；对话框关闭后焦点回到原按钮。
- 表格在 ≤760 时改成单列堆叠并隐藏表头，不横向滚动。

## 落到仓库时怎么换

1. `src/theme/tokens.ts`：按上面的 token 名替换 `T` 与 `cssVars`（保留"语义命名、单一来源"的结构），新增 `--mark` / `--mark-soft` / `--mark-strong`、`--surface-soft`、`--surface-rail`，删除 `--band-*`。
2. `src/styles/global.scss`：去掉深色顶栏相关样式，按钮改用墨实心 + 4px 圆角，焦点环改朱砂；阴影只在浮层与对话框。
3. antd 主题：`colorPrimary` → `#B03A2B`（只用于选中/焦点/链接一类），主按钮走 `Button type="primary"` 的自定义 class 改为墨实心；`borderRadius` 6→4，`colorBorder` `#CED4DA`，`boxShadow` 只留浮层用值。
4. 布局：`MainLayout` 的 64px 顶栏换成"56px 单行切换器 + 左竖轨"，`ProjectDetail` 现有五个子页保持路由不变，只换外壳与间距；运行卡从消息内联改为"触发消息下方一张卡 + 右侧轨迹面板"。
5. 触控与窄屏沿用现有 Drawer 逻辑：1100 以下群聊列与轨迹变覆盖层，900 以下竖轨转顶部横条。

## Do / Don't

- **Do** 用朱砂只标人的动作与所在位置；一个屏幕里最多两处。
- **Do** 用底色面和 1px 行界分组，留白定层级。
- **Do** 保留团队 → 项目 → 群聊三层的先后关系：项目在当前团队内干顶栏切，团队切换只在产品设置里。
- **Do** 把运行过程与人的对话分开：过程进右侧轨迹，人的消息保持在主列。
- **Don't** 恢复深色横贯顶栏、渐变、玻璃、大圆角卡片。
- **Don't** 给普通按钮上朱砂底，或让朱砂同时表示"错误"。
- **Don't** 用灰色文字做悬停效果，或让任何文字小于 12px。
- **Don't** 在项目记忆页提供编辑入口；写入只能由聊天里的 Qgent 在管理员确认后执行。
- **Don't** 为了演示状态加开关、调试面板或“切换成功/失败”按钮；状态只能由真实操作到达。
