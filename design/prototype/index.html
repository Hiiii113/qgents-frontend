    项目约定

    视觉数值只写在 src/theme/tokens.ts，页面样式只引用变量。新增页面时把专用组件、样式和测试放在同一业务目录。

    • 请求统一经 src/api/client.ts，组件不处理认证头。
    • 后端数据用 TanStack Query，全局 UI 状态用 Zustand，表单用 Ant Design Form。
    • 不引入第二套组件库、CSS 工具类框架或 any。

    接口与数据

    聊天回复使用 replyToId + content；停止执行按触发消息取消。消息、成员列表与增量同步都使用后端返回的真实 Agent ID。

    资源路径备注
    项目记忆GET /projects/{id}/memory只读，返回 markdown 原文
    项目仓库GET /projects/{id}/repos团队 App 授权范围内已导入
    运行事件GET /groups/{id}/runs/stream群级 SSE，断线用游标补齐

    已知问题

    • 多实例部署时，流式正文只在单实例内存内可见。
    • 移动端只承担读消息、回复和确认，未验证完整派活流程。

    维护方式

    写入只由聊天中的 Qgent 在项目管理员明确确认后调用工具完成，服务端核验发送者身份。前端不提供编辑入口。
