# 前端目录与实现现状

更新于 2026-11-11。产品支持默认群聊及成员创建的群聊；每个项目有自己的默认 Agent（名称 Qgent，项目之间 ID 独立），成员可申请自定义 Agent，只有显式提及群内已启用的 Agent 才触发工作。项目级 GitHub 能力默认开启，由项目管理员控制。

```text
src/
├── api/                    统一请求基础设施与当前业务接口
├── components/
│   ├── chat/               ChatPanel、输入器、虚拟列表、消息行、附件预览、同步 hook
│   ├── KnowledgeActions    Skill / Memory 详情审核操作
│   └── WorkspacePage       管理页共享布局
├── layouts/MainLayout/     当前团队首页、个人资料与团队切换浮层、通知
├── pages/
│   ├── Login/ ForgotPassword/ Welcome/
│   ├── CreateTeam/ JoinTeam/ Home/ TeamDetail/
│   ├── GitHubIntegration/  团队 GitHub App 连接
│   └── ProjectDetail/
│       ├── Chat/           项目聊天、建群与邀请
│       ├── Skill/          可复用能力
│       ├── Memory/         项目知识管理与审核
│       ├── Code/           项目仓库导入 / 移除与 GitHub 链接
│       └── Settings/       项目管理共用布局与横向导航、资料、头像、成员管理、Agent 申请、归档 / 恢复
├── query/                  QueryClient 与聊天缓存键
├── realtime/               WebSocket、团队 / 通知 SSE
├── store/                  当前团队的 UI 上下文
├── types/                  当前后端 DTO 对应类型
└── mocks/                  认证团队、项目聊天、知识与 GitHub 演示响应
```

页面使用懒加载。业务专用组件、样式与测试就近存放；只有确实共用的布局和操作抽到 components。旧任务、交付、Diff、MR、测试集、门禁、OAuth 页面以及专用 API、hooks、types、store、Mock 与对应旧协议测试已移除。

团队与项目成员管理分别统一从对应设置的成员管理标签页进入，不再提供独立项目成员路由或团队成员抽屉；群聊自己的成员名单与邀请继续在聊天中管理。

项目一级导航直接列出聊天、Agent、共享知识、Skill、仓库；项目设置只保留基本信息和成员管理。聊天页左侧是群聊二级列表（搜索、未读、新建），非聊天页不加载也不显示群列表；窄屏通过菜单按钮打开 Drawer，包含一级导航、项目设置和群聊。各业务保留现有 URL 和 groupId/messageId 定位参数。Agent 页只提交申请并列出本项目已启用的 Agent，审批由 Agent 工具执行，前端不提供独立审批操作。

共享知识是项目目录下的单个 memory.md，项目管理员可编辑，其他成员只读；前端不提供新建、审核或归档操作。Qgent 的 Memory 操作通过聊天工具完成。

聊天输入状态留在 ChatComposer，打字不重新渲染历史列表。消息列表动态高度虚拟化，只挂载可见区域及预留行；历史分页保留游标和阅读锚点，增量补齐按 ID 去重。群列表缓存精确失效，发送与已读不会重新加载全部历史。并发消息通过独立增量游标补齐，不因发送响应的较大 sequence 跳过其他成员的消息。

测试覆盖当前 API payload、导航和权限、群聊 Agent 邀请与申请、GitHub 项目开关、普通消息、回复重试、输入法、历史合并、并发增量及千条消息的有限 DOM 挂载。附件、GitHub 和真实 Qgent 执行仍需后端环境联调；Mock 不声称已经执行真实代码操作。

个人中心为顶部头像旁的浮层，点击头像更换、点击昵称就地修改；昵称保存使用 PATCH /me 返回的用户资料，头像确认成功后更新显示，无独立抽屉或上传按钮。

首页路由 /app 自动进入服务端选定团队的项目页；旧 /app/teams 列表页已删除。团队切换、创建和加入团队在顶栏团队选择器中完成，带团队头像和当前标记，保存成功后进入所选团队项目页。

当前团队项目首页以团队名称为标题，保留项目搜索和创建项目；GitHub 授权、邀请成员和团队设置入口在团队页头。项目列表按当前团队请求。

全量清理删除无入口的团队动态页、重复的跨项目会话页和独立创建项目页，连同旧深色页面主题、专用 API / 缓存键 / Mock、无引用图片与图标资源、历史 API 档案和 Task Mock 说明。当前接口以 qgents-api-current.md 为唯一对接说明。

群聊创建表单仅填写群名并选择项目成员，按需邀请本项目已启用的 Agent；默认群自动包含该项目的默认 Agent。群响应及 Mock 不保留简介字段，讨论背景通过聊天提供。
