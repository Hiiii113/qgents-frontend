# 前端视觉重构：瑞士网格 + 墨 / 纸

2026-11-13，分支 `design/refactor-v2`。规范见仓库根目录 `DESIGN.md`，token 唯一来源是
`src/theme/tokens.ts`。

## 这次改了什么

方向从「深绿品牌 + 大圆角卡片 + 柔和投影」整体换成瑞士网格：白纸底、近黑正文、单一品牌
绿强调色、1px 发丝线分区、4px 圆角、没有阴影也没有渐变、字号层级拉开、留白撑结构。

- **底座**：`tokens.ts` 定义颜色/间距/字号/圆角/动效，运行时写进 `:root`；antd 主题从同一份
  对象取值（`antdTheme.ts`），表单 label/间距/错误字号集中到 Form token。
- **骨架**：`WorkspacePage` 统一页头（标题 + 说明 + 发丝线）；顶栏改为纸底 + 下划线指示；
  个人菜单、通知中心、空态、启动兜底页全部改到纸面体系。
- **登录/引导**：左侧纯排版品牌栏 + 右侧窄栏表单，去掉渐变、光晕与卡片投影；窄屏先给表单。
- **聊天**：消息改为「头像列 + 作者/时间行 + 正文」，同一发送者连续消息只出现一次作者；
  代码消息改可折叠的等宽面板；系统消息用左侧灰线；正文与输入区收敛到 820px 阅读宽度。
- **设置/团队/仓库/技能/GitHub**：卡片降级为行 + 发丝线，表格 `size=middle`，操作列为文字
  按钮，危险操作 `--danger` + 二次确认，状态用 pill + 状态点表达。
- **交互**：点击或右键消息头像可把发送者 @ 进输入框（同时写入提及列表）；`@` 触发成员下拉；
  键盘焦点统一 2px 强调色环；`prefers-reduced-motion` 全局兜底。

## 验收

- `npx tsc -p tsconfig.app.json --noEmit`、`npx oxlint src`、`npx prettier --check`：通过
- `npx vitest run`：35 文件 / 111 用例全绿
- 机检脚本（硬编码颜色、阴影、圆角 >4px、<12px 正文、emoji 图标、旧 token 残留）：仅剩
  合规项（头像遮罩用的半透明黑、`box-shadow: none` 复位、自动填充复位、11px 眉标）
- 视觉走查：1440 与 375 宽度，覆盖登录、团队、聊天、项目设置、共享知识、项目仓库、Skill、
  GitHub、成员抽屉、个人菜单、通知中心、提及下拉
- 对比度：正文 `ink-500` 对纸底 4.91:1，强调色 5.31:1，白字压强调色 5.55:1；`ink-300`
  已降级为只用于图标与占位（占位另加了 `ink-400` ≈ 3.4:1）

## 已知未覆盖 / 后续

- 聊天里的 Agent 回复、代码消息、图片与引用消息只用 mock 的空房间验证了样式，没有真实
  会话数据走查；等后端跑起来后需要再点一遍。
- 流式渲染未实现（后端是非流式），气泡体系已按非流式设计。
- 通知中心的实时事件（WebSocket/SSE）只验证了空态与列表结构，没跑真实推送。
- 移动端聊天侧栏压成 48px 通道（群聊横滚 + 加号 + 齿轮）；如需抽屉式群列表，需要再排一版。
- `--ink-400` 与 `--ink-300` 的分工写进了 `DESIGN.md`，后续新增文案不要再往下压对比度。

## 第二轮：信息架构与实时执行

第一轮只换了视觉，导航和交互仍是旧的。第二轮把这两层一起改了。

### 导航

项目一级导航直接是「聊天 / Agent / 共享知识 / Skill / 仓库」，设置只剩基本信息与成员管理；
群聊列表只在聊天页出现，非聊天页不再挂着无关的群列表。窄屏把一级导航和群聊收进 Drawer，
关闭后焦点回到菜单按钮。

团队切换、创建、加入放在顶栏的团队选择器里，个人菜单只留账号操作。团队页头承担 GitHub 授权、
邀请成员与团队设置。

<!-- -->

共享知识从"一个只读大文本框"改成阅读文档 + 点编辑才出现编辑器：进入编辑时固定正文与版本，
编辑期间的后台刷新不会换掉保存基准；版本冲突保留草稿并提示取消后重新加载；非管理员只读。

### 聊天

消息行改成「头像列 + 作者行 + 正文」三层网格，头像 32px、`align-self: start`，长回复里不会
飘到中间。Agent 正文走 Markdown（`react-markdown` + `remark-gfm`）：代码块带语言标签和复制，
GFM 表格与长代码在自身容器内横向滚动，不开原始 HTML，外链带 `noopener`。

头像右键或点击弹出菜单，只有选中「@ 名字」才改草稿；当前群成员以外的人不给假菜单。
输入区把附件、提及、发送与快捷键提示固定在工具条上，插入提及会更换 `clientMessageId`，
避免失败重试时被后端按旧 ID 去重。

### 实时执行

后端把模型调用换成 `ChatModel.stream`，正文增量走群级 SSE（`agent-events`），阶段与工具
事件仍写事件表供现有项目 SSE / WebSocket 刷新。前端 `useAgentRuns` 把运行快照挂在触发消息
下方，按 `runId + round` 分段渲染，工具行显示真实开始/完成/失败，停止按钮只在运行中出现一次。

断线与刷新：服务端建连即下发活动运行快照，REST 快照补终态；启动时把残留 `RUNNING` 标记为
失败，不会留下永远转圈的运行。事件带 `revision`（状态版本）与 `seq`（正文缺口），旧的快照
不会把已完成的工具改回执行中。最终回复用 `clientMessageId = qgent-reply:<rootRunId>` 精确
替换临时正文，同一条消息 @ 多个 Agent 也不会互相顶掉。

### 验收

- 真实后端 + DeepSeek：`@Qgent 执行 ls` 实测 2.6s 出现「执行中 · 第 1 轮」，3.7s 工具
  「执行中」，5.2s 第 2 轮且工具完成，6.7s「已完成」，6.9s 卡片消失、正式回复出现。
- 前端 44 文件 / 183 用例、`tsc`、`oxlint`、`prettier`、生产构建全绿；后端 690 用例全绿。
- 机检脚本只剩白名单项（发丝线复位、自动填充复位、11px 眉标、头像遮罩的 token 混合色）。

### 已知边界

- 正文增量只存在当前进程内存：单实例可用，多实例下看不到别处的增量，重启会丢掉未完成正文
  （终态与最终消息仍在库里）。
- 群级 SSE 每 10 秒复检一次群成员权限，被移出后最多 10 秒内还可能在收尾。
- 工具结果里没有显式 `ok` 字段时按"结束"中性展示，不声称成功。

## 第三轮：聊天改气泡，去掉"到处一根竖线"

这一轮只改聊天页。原来的问题不是难看，而是**卖弄同一根竖线表达五件不同的事**：本人消息标记、
引用回复、输入区引用条、系统消息、Markdown 引用块。一屏望过去全是线，反而看不出谁在说话、
在回复谁。

改成 iMessage 式气泡后，含义各归其位：

| 原来                            | 现在                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------ |
| 本人消息：作者行左侧 2px 强调线 | 本人气泡靠右、`--accent-soft` 浅底、14px 圆角，文字仍左对齐                    |
| 引用回复：左侧 2px 灰线         | 气泡内顶部的小卡片（`--ink-900` 6% 混合底、10px 圆角），样式与输入区引用条一致 |
| 输入区引用条：左侧 2px 强调线   | 同样的卡片，右侧一个关闭按钮                                                   |
| 系统消息：左侧 2px 灰线         | 居中 12px 说明文字                                                             |
| Markdown 引用块：左侧 2px 线    | 凹陷底、8–10px 圆角的小块                                                      |
| 运行卡：左侧 2px 强调线         | 1px 边框 + 12px 圆角，状态靠文字和状态点                                       |

同时把"谁在连发"这层信息补上：同一人 5 分钟内连发合并成组，组内 2px、组间 20px，作者行和头像
只出现一次（组首），本人消息完全不带头像——这是 iMessage 的做法，比每条都重复名字清楚得多。
头像统一成 `--paper-sunken` 底 + 发丝线，人和 Agent 同款，Agent 只靠作者行的标签区分，不再用
黑方块（那在黑底上看着像个空缺）。

回复动作从作者行移到气泡外侧的浮层，只在 hover / 键盘聚焦时出现，不占布局；触屏没有悬停，
窄屏下常显但只留一个 ↵ 图标，避免每条消息旁边重复一个"回复"把气泡挤碎。

圆角是这轮唯一放开的规范：气泡 14px、气泡内小卡片 10px、运行卡 12px、头像 8px，其余仍 ≤4px，
`DESIGN.md` 的禁止项已按这个口径改写。群列表的消息预览现在会去掉 Markdown 记号，不再显示
`**已完成**` 这种原文。

验证：44 文件 / 184 用例，`tsc`、`oxlint`、`prettier`、`build` 全绿；mock 群 1002/901 在 1440 与
375 下气泡圆角 14px、聊天区内"只在左侧出现或 ≥2px 的边框"为 0、375 无横向滚动、本人头像 0 个、
分组间距 20/2/32 正确。
