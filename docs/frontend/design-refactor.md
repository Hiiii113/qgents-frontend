# 前端视觉重构：瑞士网格 + 墨 / 纸

2026-11-13，分支 `design/refactor-v2`。规范见仓库根目录 `DESIGN.md`，token 唯一来源是
`src/theme/tokens.ts`。

## 这次改了什么

方向从「深绿品牌 + 大圆角卡片 + 柔和投影」整体换成瑞士网格：白纸底、近黑正文、单一品牌
绿强调色、1px 发丝线分区、4px 圆角、没有阴影也没有渐变、字号层级拉开、留白撑结构。

- **底座**：`tokens.ts` 定义颜色/间距/字号/圆角/动效，运行时写进 `:root`；antd 主题从同一份
  对象取值（`antdTheme.ts`），表单 label/间距/错误字号集中到 Form token。
- **骨架**：`WorkspacePage` 统一页头（标题 + 说明 + 发丝线）；顶栏改为纸底 + 下划线指示；
  个人菜单、通知中心、空态、启动兜底页全部改到纸面体系。
- **登录/引导**：左侧纯排版品牌栏 + 右侧窄栏表单，去掉渐变、光晕与卡片投影；窄屏先给表单。
- **聊天**：消息改为「头像列 + 作者/时间行 + 正文」，同一发送者连续消息只出现一次作者；
  代码消息改可折叠的等宽面板；系统消息用左侧灰线；正文与输入区收敛到 820px 阅读宽度。
- **设置/团队/仓库/技能/GitHub**：卡片降级为行 + 发丝线，表格 `size=middle`，操作列为文字
  按钮，危险操作 `--danger` + 二次确认，状态用 pill + 状态点表达。
- **交互**：点击或右键消息头像可把发送者 @ 进输入框（同时写入提及列表）；`@` 触发成员下拉；
  键盘焦点统一 2px 强调色环；`prefers-reduced-motion` 全局兜底。

## 验收

- `npx tsc -p tsconfig.app.json --noEmit`、`npx oxlint src`、`npx prettier --check`：通过
- `npx vitest run`：35 文件 / 111 用例全绿
- 机检脚本（硬编码颜色、阴影、圆角 >4px、<12px 正文、emoji 图标、旧 token 残留）：仅剩
  合规项（头像遮罩用的半透明黑、`box-shadow: none` 复位、自动填充复位、11px 眉标）
- 视觉走查：1440 与 375 宽度，覆盖登录、团队、聊天、项目设置、共享知识、项目仓库、Skill、
  GitHub、成员抽屉、个人菜单、通知中心、提及下拉
- 对比度：正文 `ink-500` 对纸底 4.91:1，强调色 5.31:1，白字压强调色 5.55:1；`ink-300`
  已降级为只用于图标与占位（占位另加了 `ink-400` ≈ 3.4:1）
